# 🚀 Boost Searcher（本地搜索引擎）

## 📌 项目简介

本项目是一个基于 **C++ + Boost + Linux** 实现的轻量级本地搜索引擎服务，支持对文本数据进行索引构建与关键词检索，并通过 HTTP 提供查询接口。

项目从零实现搜索引擎核心流程，包括数据预处理、倒排索引构建、查询解析及结果返回，适合作为后端系统设计与网络编程的实践项目。

---

## 🧱 技术栈

* **C++11/14**
* **Boost（Asio / Beast）**
* **Linux（开发与部署环境）**
* **HTTP 协议**
* 数据结构与算法（倒排索引、字符串处理）

---

## ⚙️ 核心功能

* 🔍 **关键词搜索**

  * 支持输入关键词进行匹配查询
* 📚 **倒排索引构建**

  * 提升查询效率，实现快速检索
* 🌐 **HTTP 服务**

  * 基于 Boost 实现轻量级 Web 服务
* 🧩 **模块化设计**

  * 索引构建、查询解析、网络服务解耦

---

## 🏗️ 项目结构

```bash
.
├── parser.cc        # 数据解析
├── searcher.hpp     # 搜索核心逻辑
├── server.cc        # HTTP服务
├── search_server    # 可执行程序
├── util.hpp         # 工具函数
```

## 🚀 运行方式

### 1️⃣ 环境准备

```bash
g++ --version
# 需要支持 C++11 及以上
```

安装 Boost：

```bash
sudo apt install libboost-all-dev
```

---

### 2️⃣ 编译项目

```bash
g++ -std=c++11 server.cc -o search_server -lboost_system -lpthread
```

---

### 3️⃣ 启动服务

```bash
./search_server
```

---

### 4️⃣ 测试接口

浏览器访问：

```
http://127.0.0.1:端口/?query=关键词
```
